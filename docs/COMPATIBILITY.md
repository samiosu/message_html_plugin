# 動作確認環境と確認範囲

確認日: 2026-10-27

## 対象環境

- Windows上のTyrano Studio v6.03付属プロジェクトで使用されているTyranoScriptを対象にしています。
- 同梱エンジンの `readme.txt` は Ver6.00、内部の `tyrano.plugin.kag.version` は `520` という表記です。この配布物は、その実装のメッセージ描画APIを対象にしています。
- ブラウザでの検証は、Microsoft Edgeで実際のTyranoScriptエンジンを起動して行いました。
- TyranoScript本体、jQuery、本体付属の画像やキャラクター素材は同梱していません。導入先プロジェクトで提供されるものを使用します。

## 確認した機能

元プロジェクトの統合テストでは、次の11項目を確認しています。

1. 太字・斜体・色・文字サイズ・HTMLエンティティの表示。
2. 装飾された本文の文字送りと、クリックによる表示の短縮。
3. `[emb]`, `[font]`, 物理的な改行をまたぐ装飾。
4. `[l]`, `[r]` をまたぐ装飾と、`[p]` 後のリセット。
5. HTMLルビ・画像・改行と、縁取りを使う場合の瞬間表示。
6. タグだけの本文や、禁則処理の設定を有効にした場合のシナリオ進行。
7. バックログの装飾、エンジンのDOM保存・復元関数、ゲーム状態を復元した後の装飾の継続。
8. 対応対象外のタグの文字表示、イベント属性の除去、予約クラスの除去。
9. HTMLの有効・無効の切り替えと、従来の `[ruby]` との併用。
10. 元プロジェクトのタイトル画面からデモを開き、クリックで進み、タイトルへ戻る操作。
11. 上記の操作中のブラウザ実行時エラー。

配布用サンプルについても、配布フォルダのファイルを説明書どおりの順序で読み込む構成で実行し、次の10項目が通ることを確認しました。プラグイン・サンプル・CSS・画像は、配布フォルダ内のファイルを使用しています。

1. 説明書の読み込み順でプラグインを導入して起動。
2. 元プロジェクトのタイトルや背景を使わずに本文を表示。
3. 同梱CSSクラスの適用。
4. 変数の埋め込みとクリック待ち後の装飾の維持。
5. 同梱SVGアイコンとHTMLルビの表示。
6. HTMLタグとエンティティの書き方のサンプル表示。
7. HTMLの無効化と再有効化。
8. サンプル終了後の呼び出し元への復帰。
9. ブラウザ実行時エラーがないこと。
10. サンプルの依存ファイルに読み込み漏れがないこと。

## 確認範囲の境界

- セーブについては、エンジンのDOM保存・復元関数と、JSON化したゲーム状態を使う復元を確認しています。セーブ画面・ロード画面から保存スロットを選択する操作は、今回の自動テストの対象に含めていません。
- 読み上げにはタグを除いた本文を渡す実装ですが、実際の音声出力の聴き取りは確認していません。
- スマートフォン実機、各OS向けの実行ファイル、縦書き、チャット表示、すべての縁取り・文字アニメーションの組み合わせ、他のメッセージ描画プラグインとの併用は一括して確認したものではありません。
- 他のバージョンのTyranoScriptへの互換性は、バージョン番号だけで判断せず、導入先のプレビューと実際の配布形式で確認してください。

## エンジン更新時

このプラグインは、`text.showMessage`, `buildMessageHTML`, `addChars` などのメッセージ描画処理を拡張しています。Tyrano本体を更新した場合は、同梱サンプルで表示と進行を確認してください。

プラグインの動作そのものにNode.jsは必要ありません。元プロジェクトの自動テストは開発時の確認用です。
